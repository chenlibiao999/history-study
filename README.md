# 历史学习工作台

这是一个按地区、朝代、国家和文明拆分的历史学习数据项目，目标是把真实史实整理成可追溯、可浏览、可复习的主线。

## 运行

直接打开 `index.html`，或使用任意静态文件服务器托管项目根目录。

## 主要结构

- `index.html`：页面骨架。
- `assets/`：界面样式与交互。
- `data/index.js`：数据汇总入口。
- `data/dynasties/<dynastyId>/`：按朝代或主体拆分的数据模块。
- `data/regions/`：区域索引和跨区域组织，不复制事件正文。
- `data/topics/`：跨朝代、跨文明专题。
- `data/rules/`：正式规则文档，唯一规则来源。
- `data/schema.md`：数据字段契约，不承载内容政策。
- `scripts/`：规则校验、覆盖审计和质量审计。

## 规则入口

正式规则见 [`data/rules/00-index.md`](data/rules/00-index.md)。
`data/rules.md` 仅保留兼容索引；README、PRODUCT、区域说明和任务归档不能覆盖正式规则。

## 当前能力

- 按时间、区域、主题和主体浏览事件。
- 展示人物、因果链、史料、引用、疆域人口和历史地图。
- 支持帝王或统治者与事件的关联跳转。
- 过程节点提供白话解释，古籍链接作为出处而非纯原文展示。
