# 升级重写规则

## REWRITE-001 目标与分层

- 状态：`active`
- 适用范围：全库事件内容与页面展示。
- 规则：项目应成为层次明确、可连续阅读的历史书，而非将所有事件扩成同样篇幅。每条事件必须归为 `core`（核心案例）、`mainline`（主线节点）或 `outline`（索引线索）。
- 内容边界：核心案例负责解释，主线节点负责连接叙事，索引线索只保留准确定位。模板化过程先移出正文，不得仅改写措辞后保留为假深度。
- 审计方式：每批输出三类数量、未分层事件和模板过程清单。
- 展示保护：`contentLevel` 本身不得隐藏既有正文；仅在模块完成逐条人工分层、数据明确标记 `contentPresentation: "tiered"` 后，页面才可按层级精简展示。未标记的存量事件必须保留全部既有详情。

## REWRITE-002 三类质量门槛

- `core`：必须有事件独有问题、具体机制、可核查材料锚点；仅在解释需要时补充反误解、人口/疆域或地图。
- `mainline`：必须有准确摘要、前后连接、必要人物和统一时间；不要求伪造完整过程。
- `outline`：不得展示伪造的背景、过程、结果、来源或影响；只保留标题、时间、地域和必要定位。
- 无来源、无材料或无解释价值的事件不得升级为 `core`。

## REWRITE-003 区域批次

1. 南亚、东南亚；
2. 西亚、中亚、欧亚交界；
3. 东亚与中国主线；
4. 地中海与欧洲；
5. 非洲、美洲、大洋洲。

每批只处理一个模块；完成后进行内容抽查、页面验证、规则校验、提交和远端推送。

## REWRITE-002A 卡片独立性与合并

- 状态：`active`；适用范围：全库，包含已完成和待重写的所有区域、国家、朝代与时期。
- 独立卡片必须是一个可单独学习的单位：能够提出独有问题，说明具体机制，给出材料锚点，并构成不同的因果转折。
- 仅是大过程中的一步、地点、人物、日期或结果的事件，不得以一句摘要保留为独立卡片；应并入能够解释该过程的父卡，写成 `process` 节点或索引锚点。
- 合并时必须保留原事件名称、时间和关键词；知识不能因减少卡片而丢失。父卡的过程节点应说明该步骤在机制中的作用，而非只罗列名称。
- 不允许为了维持事件数量保留空壳、索引线索或模板化过程。存在真实独立解释价值但边界难判的卡片，才列入待确认清单。

## REWRITE-002B 开元核心卡落地标准

- 状态：active；适用范围：全库已完成、正在重写和新建的事件卡。
- 共同底线：只陈述事实与可追溯的逻辑链；禁止主观价值判断、道德评判、代入式决策、个人迁移和学习活动设计。所有解释性文字须标为 [解释层] 并有来源或 [争议]；可直接核对的记载标为 [事实层]。
- 时间与空间：每张卡使用统一可排序时间格式，并写明公元时间、朝代/政权语境和必要的地点。核心卡还须说明行政区、交通、地形或行动空间如何影响事件；不可用现代行政边界替代历史空间。
- core 与时代性阶段：以“开元之治”卡为最低样板。详情页所有可见栏目都必须完整，而非只扩写背景正文：
  - background 说明此前形成的具体条件；
  - process 至少 3 个具有事实差异的阶段，按时间写清参与者、行动、制度或资源变化，以及每一阶段如何导向下一阶段；
  - results 分为即时影响、中期影响和后续关联，区分政治、经济、社会、文化、军事外交中实际相关的维度；
  - debates 写成材料边界、解释竞争或范围限制，不得出现“学习提示”或价值判断；
  - claims 至少包括事实判断与机制判断；每条绑定准确 sourceIds、置信度和断言边界；
  - causalChain 至少展示前置条件、制度/资源中介、即时结果和后续关联，避免“背景—展开—影响”空泛三段式；
  - learningCase 只用于呈现事实层、解释层、多因排序、传导机制、有限反事实和争议边界；不得用记忆口诀、角色代入或虚构问答填充。
- 多因与机制：核心卡须区分 [主因]、[辅因] 与 [争议因]；主因应接受有限反事实检验，即说明“缺少该条件时结果是否仍可能发生”及其不确定性。传导不得跳步，须写成 A → 中介 → 中介 → B，每段对应材料。
- 来源：每一关键事实和解释均能在 sources、citations、claims.sourceIds 间回溯。编年史、制度志、人物传、出土材料或研究各自只支持其直接材料范围；不得将单一史料外推为总人口、普遍生活水平、完整疆界或必然因果。
- 地图、疆域与人口：核心卡仅在确有直接解释价值且有合格来源时附 0-1 张事件级地图和必要的 1 条疆域/人口数据。没有可追溯快照时保持空状态并说明原因，禁止自制示意图、装饰图或跨期地图填空。
- mainline：至少保留准确时间空间、可核查摘要、前后关联和必要来源；若承担因果解释，则按上述事实/解释与来源要求补全，不得以一句话冒充完整过程。
- outline：只保留准确定位、时间、地域和关联；不得显示伪造的背景、过程、结果、争议或来源。信息不足时合并进能够解释机制的父卡，保留原名称和时间作为过程节点。
- 交付验收：核心卡逐栏检查 background / process / results / debates / claims / citations / causalChain / sources / map；任何一个仍为旧摘要、无来源断言、空泛“影响深远”或与正文矛盾，均视为未完成。

## REWRITE-004 辅助资料归位

- 事件页默认最多展示 1 条人口/疆域和 0-1 张地图；确有比较必要时最多各 2 条。
- 完整人口、疆域和地图时间序列归入地区或政体概览。
- 图片只服务正在解释的事实，不作装饰性填充。

## REWRITE-005 全库验收

- 不得存在统一过程模板、`undefined` 或无效来源绑定。
- 核心案例应能回答：为什么发生、怎样推进、为什么重要、哪些地方不能过度理解。
- 静态页面、筛选、搜索、详情、地图与数据校验必须回归。
